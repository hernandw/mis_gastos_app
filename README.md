# 💰 Mis Gastos Pro

Una aplicación web moderna y ligera desarrollada para el control financiero mensual en CLP, con gráficos de torta interactivos, múltiples cuentas, categorías personalizadas, importación/exportación en formatos JSON y CSV, respaldo local y una **regla de control estricto que impide registrar gastos si no cuentas con ingresos**.

## ✨ Características Principales

* **📊 Gráfico de Torta Interactivo:** Visualiza de forma inmediata en qué categorías gastas más cada mes (Comida, Transporte, Alojamiento, Salud, etc.).
* **🔒 Regla de Control de Ingresos:** Sistema de validación que bloquea el registro de gastos si la aplicación no posee ingresos registrados.
* **🏦 Gestión de Cuentas:** Administra múltiples cuentas (Efectivo, Cuentas Bancarias, Inversiones)[cite: 3] con saldos actualizados en tiempo real.
* **🏷️ Categorías Personalizables:** Agrega nuevas categorías tanto para ingresos como para gastos según tus necesidades.
* **📥📤 Importación y Exportación JSON / CSV:** Compatible con respaldos estructurados en JSON y archivos CSV para análisis externo.
* **💾 Respaldo Local (LocalStorage):** Tus datos se guardan de forma segura en tu navegador.
